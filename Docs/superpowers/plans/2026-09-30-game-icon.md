# Game Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать и сохранить в Unity-проекте финальную иконку «Ходьбы» с пустым пепельным горизонтом и уходящей вдаль цепочкой следов.

**Architecture:** Изображение создаётся встроенным генератором по утверждённой спецификации. Результат визуально проверяется в полном размере и как маленькая иконка, после чего выбранный PNG копируется в отдельную папку брендовых ассетов без изменения существующего арта.

**Tech Stack:** встроенный ImageGen, PNG 1024×1024, Unity asset tree, локальная визуальная проверка.

---

### Task 1: Создать финальный арт

**Files:**
- Reference: `Docs/superpowers/specs/2026-09-30-game-icon-design.md`
- Create: `Assets/Hodba/Art/Branding/Icon_Hodba.png`

- [ ] **Step 1: Сформировать производственный prompt**

В prompt явно зафиксировать квадратную композицию, высокий пустой горизонт, крупные следы у нижнего края, их уменьшение в перспективе, отсутствие человека и суровую живописную манеру.

- [ ] **Step 2: Сгенерировать изображение**

Использовать встроенный ImageGen в режиме `stylized-concept`, без прозрачного фона. Не добавлять текст, рамку или скругление углов.

- [ ] **Step 3: Проверить смысловые ограничения**

Открыть результат в полном размере и подтвердить: в кадре нет человека и точек интереса; следы анатомически убедительны и чередуются; пустота доминирует; ближайшие отпечатки хорошо читаются.

- [ ] **Step 4: При необходимости сделать одну целевую правку**

Если нарушено ограничение, изменить только конкретный дефект — например, убрать силуэт или увеличить ближайшие следы — сохранив композицию, палитру и живописную фактуру.

### Task 2: Поместить и проверить ассет

**Files:**
- Create: `Assets/Hodba/Art/Branding/Icon_Hodba.png`

- [ ] **Step 1: Создать папку назначения**

Создать `Assets/Hodba/Art/Branding`, не меняя существующие игровые ассеты.

- [ ] **Step 2: Скопировать выбранный PNG**

Сохранить финальный вариант как `Assets/Hodba/Art/Branding/Icon_Hodba.png` без перезаписи другого файла.

- [ ] **Step 3: Проверить технические свойства**

Убедиться, что файл открывается, имеет квадратный размер 1024×1024 и пригоден для импорта Unity как обычная RGB/RGBA-текстура.

- [ ] **Step 4: Проверить уменьшенный вид**

Просмотреть иконку в малом размере: крупные следы должны оставаться главным читаемым акцентом, а горизонт — сохранять ощущение пустоты.

- [ ] **Step 5: Зафиксировать результат**

Добавить только финальный PNG и связанные с задачей документы, не включая посторонние изменения рабочего дерева.
