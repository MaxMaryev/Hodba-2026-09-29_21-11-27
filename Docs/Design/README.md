# Ходьба — дизайн по блокам

Концепт разбит на блоки, которые можно развивать по отдельности. В каждом файле записано, что решено, что предлагается, что открыто и с чем блок связан.

## Источники и их вес

1. **[Ходьба-концепт.md](Ходьба-концепт.md)** — дух игры, собранный из нескольких лет разговоров. Если что-то расходится с духом, прав дух.
2. **Решения, принятые при разборе** — записаны в блоках с пометкой «решено».
3. **[concept-sketch.md](concept-sketch.md)** — первый письменный набросок. Он мягче духа, и там, где они расходятся, набросок уступает. Все расхождения собраны в [forks.md](forks.md).

Проверочная фраза из разговоров: если идея нарушает дух, это «уже другая концепция».

## Статусы

- **решено** — направление выбрано
- **предложение** — есть проработанный вариант, нужно подтвердить
- **открыто** — есть только вопросы и варианты

## Первая веха: «Поле»

Прямо из разговоров: небольшое поле-пустыня и одна хорошая анимация ходьбы от первого лица с покачиванием. Больше ничего.

Вопрос, на который отвечает веха: **волшебна ли пустота сама по себе?** Если нет, никакое наполнение её не спасёт. Если да, дальше можно строить.

Что для неё нужно: [02](02-world-generation.md) (заглушка), [04](04-camera-presence.md) (первое лицо), [05](05-walking.md) v0, [15](15-sound.md) (ветер и шаги), [09](09-sky-weather.md) (солнце).

Проверяется **на Android-телефоне, в наушниках**, а не в редакторе.

## Правила работы с файлами

- Одно решение записывается в одном месте, остальные блоки на него ссылаются.
- Закрытый вопрос переносится в раздел «Решено» с датой.
- Если меняется закон, это делается открыто, в [00](00-laws.md), с причиной.
