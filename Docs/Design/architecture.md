# Архитектура и модульность

**Статус:** предложение · **Касается:** всех блоков

Главное требование: блоки разрабатываются и переделываются независимо. Сильнее всего это касается генерации мира: её будут переписывать много раз, возможно, полностью.

## Слои

```
┌────────────────────────────────────────────────────────────┐
│ Клиент (Unity): первое лицо, тело, рендер, звук, бумага     │  ← меняется часто
├────────────────────────────────────────────────────────────┤
│ Клиентская логика: предсказание, кэш мира, голос рации      │
├────────────────────────────────────────────────────────────┤
│ Ядро симуляции (чистый C#, без UnityEngine)                 │  ← общее для клиента и сервера
│   путь · тело · автономия · погода · находки · внимание     │
├────────────────────────────────────────────────────────────┤
│ Контракт мира (IWorldQuery)                                 │  ← меняется редко и осторожно
├────────────────────────────────────────────────────────────┤
│ Генератор мира (реализации контракта)                       │  ← меняется часто и сильно
└────────────────────────────────────────────────────────────┘

Сервер: авторитетная симуляция · слой следов · соседство (пространственный индекс)
        · загадка (ответ хранится только здесь) · голосовой ретранслятор · модерация
```

## Принципы

1. **Ядро симуляции не знает про Unity.** Отдельная сборка (`noEngineReferences: true`), которая собирается и в клиент, и в .NET-сервер.
2. **Мир закрыт контрактом.** Никто не вызывает генератор напрямую. Генератор можно заменить целиком.
3. **Созданное игроками не зависит от генератора.** Следы, пирамидки, тайники, тела, листы бумаги — это слой следов на сервере: координаты плюс снимок. Смена генератора не меняет прошлое игроков.
4. **Сервер авторитетен.** Время, путь, тело, погода, находки и смерть определяет сервер. Часам клиента не доверяем.
5. **Данные отдельно от кода.** Вещи, материалы, места, таблицы наполнения, параметры тела живут в данных.
6. **Детерминизм в авторитетной части.** Проходимость, линии, места, вода, погода считаются одинаково на сервере и клиенте: целочисленный хэш-шум, никаких различий в `float` между платформами.
7. **Секрет загадки не отдаётся клиенту заранее.** Всё, что раскрывает загадку, клиент получает только в момент, когда оно попадает в поле зрения ([19](19-mystery.md)).

## Сборки (черновик)

| Сборка | Содержимое | Зависит от |
|--------|-----------|------------|
| `Hodba.Core` | математика, координаты (`long`), время мира, общие типы | — |
| `Hodba.World.Contract` | `IWorldQuery`, типы ответов | Core |
| `Hodba.World.Gen.*` | реализации: `FlatStub`, `AshV1`… | World.Contract |
| `Hodba.Sim.Walk` | отрезки пути, намерения, привычки, линии | Core, World.Contract |
| `Hodba.Sim.Body` | тело: вода, тепло, усталость, кожа, ноги | Core |
| `Hodba.Sim.Sky` | солнце, звёзды, луна, погода как функция (место, время) | Core, World.Contract |
| `Hodba.Sim.Things` | определения вещей, наполнение мест, внимание | Core, World.Contract |
| `Hodba.Sim.Mind` | автономия: человек без игрока ([21](21-autonomy.md)) | Core, Sim.Walk, Sim.Body, Sim.Sky |
| `Hodba.Net` | протокол клиент ↔ сервер | Core, Sim.* |
| `Hodba.Client.*` | камера, тело, ввод, рендер мира, звук, бумага | всё выше + UnityEngine |
| `Hodba.Server` | отдельный .NET-проект: слой следов, соседство, загадка, голос | Core, World.*, Sim.*, Net |

**Клиент — Android** (IL2CPP, ARM64). Поэтому детерминизм в авторитетной части — не пожелание, а требование: сервер x64 и телефон ARM64 должны получать одинаковый мир.

## Инструменты (рано)

- **Просмотрщик мира** на любом масштабе.
- **Прогонщик путников:** тысячи ботов с настоящими привычками и телом. Статистика: вода, города, чужие следы, смерти, длина пустых участков. Это главный инструмент настройки редкости.
- **Вид с высоты глаз** из любой точки: что видно на горизонте.

## Открытые вопросы

- Стек сервера и хранилище: ASP.NET и что для пространственных запросов (PostGIS, свой grid)?
- Голос: своё решение или готовый сервис (Vivox и подобные) с каналами по радиусу?
- Мир на клиенте генерируется локально (сид плюс версия) или частично приходит с сервера?
